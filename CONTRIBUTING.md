We welcome contributions from the community to make PR reviews even faster and more deterministic!

1. Clone this repo:
   `ash
   git clone https://github.com/Priyanshu123-coder/pr-architect-play.git
   cd pr-architect-play

2. Inspect with Rote:
   `ash
   rote play inspect https://play.modiqo.ai/priyanshu-patel/summarize-github-pr@0.0.1
